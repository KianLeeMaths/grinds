# Kian Lee — Leaving Cert Grinds

A simple English landing page for private Leaving Cert grinds and violin lessons.

**Live site (after setup):** `https://kianleemaths.github.io/grinds/`

## Subjects

- Maths
- Applied Maths
- Physics
- Chemistry
- Music
- Violin

## Before publishing

1. Open `config.js` and set your real WhatsApp number:

```js
whatsappNumber: "353871234567",  // no + or spaces
```

2. Adjust the default enquiry message if you like.

## GitHub Pages

1. Push this repo to `https://github.com/KianLeeMaths/grinds`
2. On GitHub: **Settings → Pages**
3. **Source:** Deploy from branch `main`, folder `/ (root)`
4. Save — the site will be live in a minute or two

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`
